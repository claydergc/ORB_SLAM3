## 2. Modified Files — `src/`

### `Frame.cc` *(~670 diff lines)*
New methods added: 

`Frame::Frame(imGray)`: N was initialized to N_Cam0. N_Cam1 was initialized to N+1. This is important to initialize correctly
`Frame::Frame(imGray, imPolarized)`: New constructor overload for polarization-camera input. N_Cam0 is obtained from the originalORBExtractor and N_Cam1 is obtained from the polarization-camera ORBExtractor. N_Cam0 and N_Cam1 are important because they indicate where features from each camera are located in data structure that stores all features. mvKeysCam0/1, mDescriptorsCam0/1, stores features from each camera separately and then they are combined into `mvKeys` and `mDescriptors` for the entire frame.

`computeFeatureOverlap`: Computes the overlap between features from two images from different cameras.

`GetFeaturesInAreaCam`: Computes the features in an area of the image from a specific camera. Here is where N_Cam0/1 are used to determine which features belong to which camera. This method is later used in the SearchByProjection and SearchForTriangulation methods in ORBmatcher class.


### `FrameDrawer.cc` / `FrameDrawer.h` *(~800 / 132 diff lines)*
No new named functions — changes are inside existing drawing functions, adding awareness of per-camera keypoint counts (`N_keys_Cam0`, `N_keys_Cam1`) for the multi-camera visualization.

### `KeyFrame.cc` / `KeyFrame.h` *(~147 / 42 diff lines)*
New methods: `ComputeBoWCam`, `GetFeaturesInAreaCam`, `AddMapPointPolcam`, `countMapPoints`.

`GetFeaturesInAreaCam`: Works in a similar way to `GetFeaturesInArea` from Frame class. This method is necessary because there are SearchByProjection methods that works with KeyFrames and not Frames.

New members: per-camera keypoint/descriptor storage mirroring `Frame` (`mvKeysCam0/1`, `mvKeysUnCam0/1`, `mDescriptorsCam0/1`, `mBowVecCam0/1`, `mFeatVecCam0/1`, `mGridCam0..3`, `N_Cam0/1`).
Constructor bodies (`KeyFrame::KeyFrame(...)`) updated to initialize/copy these new members.

`CreateNewMapPoints`: This method now uses the method SearchForTriangulationInEachCam() from ORBmatcher class to create new map points from triangulation with matches done from features in each camera.

### `ORBmatcher.cc` / `ORBmatcher.h` *(~4390 / 238 diff lines — largely formatting)*

`SearchForTriangulationInEachCam(...)`: Searches for matches between 2D features in each camera and triangulates new map points differentiating between camera 0 and 1. The differentiation is done using N_Cam0/1 counts, such as if (pMP1 || idx1>=pKF1->N_Cam0).

`SearchForInitialization(...)`: This method is the original one but with one replacement of GetFeaturesInArea() with GetFeaturesInAreaCam() from Frame class.

`SearchByProjection(Frame &CurrentFrame, const Frame &LastFrame, ...)`: This method is the original one but with one replacement of GetFeaturesInArea() with GetFeaturesInAreaCam() from Frame class.
